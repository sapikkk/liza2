# liza2

Static landing page Petani Juara SawitPRO.

- **Single file:** `index.html` (markup, CSS, and JavaScript).
- **Local assets:** `assets/` (favicon, Google Play badge, hero fallback PNG).
- **Remote media:** Wix CDN URLs for hero, winner photos, and MP4 videos.

Open `index.html` in a browser or serve this directory with any static file server.
